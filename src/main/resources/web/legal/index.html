Source code offer

The installers contain the OpenJDK runtime of Eclipse Temurin (GPL-2.0 with Classpath Exception) and Remote Tea (LGPL-2.0). The complete corresponding source code of the exact versions is attached to each release (OpenJDK21U-jdk-sources_<version>.tar.gz and remotetea-oncrpc-1.1.4-sources.jar) on github.com/skyplayser/LJ-Link/releases. For at least three years after each release we will also send it to anyone on request; write to anfrage@nextphilm.de.
