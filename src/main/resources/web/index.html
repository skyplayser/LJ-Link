What are the DJs playing right now?

LJ Link shows live which track is playing on every player and where it is.

This view is read-only. To start, open LJ Link on the computer itself.

Finds Pioneer and Denon devices at the same time. Devices that are switched on later are added by themselves.

  1. ConnectComputer, players and mixer on the same network switch, with cables.
  2. SearchOne button finds every player, from any maker.
  3. WatchHere or on a tablet in the same network: every deck, every waveform, live.

        Settings

        Seconds of the detail waveform that are visible. Smaller value = closer.
        Waveform colors
        RGB shows the colors of the player (bass, mids, highs). Blue is the classic look.
        Display
        Devices
        Everything that is found is shown. Untick a device to hide its players, for example when several floors are in the network. A new device that appears later is added automatically.
        Screen
        On an iPad or iPhone without HTTPS this is a stopgap. More reliable: in the iPad settings set “Display & Brightness → Auto-Lock: Never” (with the charger connected). Also switch Low Power Mode off: on the iPhone it shortens Auto-Lock to 30 seconds, probably on the iPad too.
        Stops this device from dimming or locking the screen while LJ Link is shown, like a playing video. On an iPad opened over the network, tap the page once; LJ Link then tries to keep the screen on. On a Mac LJ Link also keeps the computer from falling asleep while a browser shows it.
        Privacy mode
        Hides title, artist, album and cover. It can only be changed with the program icon: menu bar (Mac) or taskbar next to the clock (Windows) → click the icon → tick “Privacy mode”. It cannot be changed in the web interface, not even from a tablet.
        Ableton Link
        Every program with Ableton Link in the network (Ableton Live, Resolume, Traktor, apps …) then runs at the tempo of the deck chosen in SEND BPM (Auto: the master). Beats and bars follow the beat grid of Pioneer and Denon decks. Switch Link on in the other program too.
        Updates
        LJ Link asks GitHub for the newest version about 15 seconds after the start (only when the program icon is shown) and when the interface is loaded, at most once an hour. Only this computer asks, also when a tablet loads the page; GitHub sees its IP address and the program version. When this is off, GitHub is only asked when you choose “Check for updates” in the program icon menu.
        Quit
        When you quit LJ Link from the program icon, a short note first asks for feedback (with an optional star rating) and offers the link to share. Nothing is sent from it.
        Feedback

        Send BPM

        Fixed value BPM
        Auto takes the tempo master; without a master the deck that is on air and playing. Manual always takes the chosen deck, even when another one is live. Fixed value is a deck of its own that sends the tempo you type in, for tests or when no DJ gear is connected.

        Known problems and solutions

        Program and system version, network adapters, the devices that were found and their connection state, what each deck receives (waveform, beat grid, cues) and the last log lines. No track titles, no covers, no passwords.
