Light deskgrandMA2 and onPC

The tempo of the DJs on a speed master of your show. Tested on a real grandMA2 onPC.

Status

Stable

  • Found by the search, login and the command SpecialMaster 3.16 At 128 were confirmed on a real grandMA2 onPC.
  • A hardware console has not been tried by us yet. It uses the same remote command line.

How it works

The grandMA2 has no OSC input. So LJ Link connects to the command line of the desk like a Telnet program (TCP port 30000), logs in as a user of the show and types the command for the speed master.

1. On the desk: switch Telnet on

  1. Press Setup on the grandMA2 (or in grandMA2 onPC).
  2. Tap Console, then Global Settings.
  3. Find the entry Telnet and set it to Login Enabled.

As long as Telnet is off (Login Disabled) the search still finds the desk, but it takes no commands.

2. On the desk: a user for LJ Link

Every Telnet connection logs in as a user of the show. User name and password are case sensitive. MA Lighting recommends a user of its own for remote control:

  1. Create a new user in the user management of the show (Setup → Console → User & Profiles), for example lj.
  2. Give it a password, for example link.
  3. The user needs the right to change speed masters (at least Playback, if in doubt Program). Otherwise the desk answers Error #44 INSUFFICIENT USER RIGHTS.
  4. Save the show. Users are stored in the show.

It also works without your own user: every show has the users Administrator with the password admin, and Guest. LJ Link enters administrator / admin as the default. If the password was changed in your show, enter the right one. Because this default is public, change it in shows that run in an open network.

3. On the desk: prepare the speed master

  1. Decide which speed master gets the tempo. The grandMA2 has Speed 1 to 15 and Speed 16 = BPM. In the command line they are SpecialMaster 3.1 to SpecialMaster 3.16. Assign the effects and chasers that should run in time to this speed master.
  2. Test by hand: type this into the command line and press Enter.
SpecialMaster 3.16 At 120

The speed master should now show 120 BPM (see the Masters window) and the assigned effect should run in time.

4. In LJ Link

  1. Open the menu (☰) → Light desk link (send tempo), or click the tab LINK at the top.
  2. Choose grandMA2 / grandMA2 onPC (Telnet).
  3. Press Search for the desk and click the grandMA2 that was found, or enter the IP address by hand (onPC on the same computer: 127.0.0.1).
  4. The port stays 30000.
  5. User and password: administrator / admin is entered by default. Change it only if your show uses another one.
  6. Choose the speed master: Speed 16 (BPM) is the default, or Speed 1 to 15.
  7. The command is SpecialMaster 3.16 At {bpm} by default. The tempo replaces {bpm} as a whole number, because the command line takes no decimals (At 128.0 does nothing).
  8. Press Save, then Send test (120 BPM). The speed master should jump to 120.

Good to know

  • Every command lands in the command history of the desk. That is why an unchanged tempo is repeated only every 15 seconds.
  • Do not go into the fixture setup or the schedule over Telnet: according to MA that locks access for other users without warning. LJ Link only sends the command you entered.

Problems

The desk does not react
  1. Is Telnet on (Login Enabled)? Is the IP address right, and is the computer in the same network?
  2. Is the effect assigned to the speed master you send to (Speed 16 by default)?
  3. Does the manual test SpecialMaster 3.16 At 120 work in the command line of the desk?
Error #44 INSUFFICIENT USER RIGHTS
  1. The user may not change masters. Give the user more rights on the desk, for example Admin, and save the show.
Login failed
  1. User name and password are case sensitive. Check them in the user management of the show.
The tempo has no effect, although the command arrives
  1. The grandMA2 takes whole BPM only. LJ Link 1.3.0 and newer send them that way.
