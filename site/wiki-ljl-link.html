LJL Link · alphaLJL Link: Serato DJ Pro in the booth

The DJ’s Serato decks in LJ Link, straight from the club’s USB stick. Nothing to install, passive, track names only with the DJ’s OK.

αAlpha: tested locally, not in a club yet

LJL Link is new and an alpha. It was tested locally on one Mac with Serato DJ Pro 5.0, not yet in a real club, and it is not notarized by Apple. Do not rely on it for a show; keep a fallback ready, for example tap tempo on the desk. It needs LJ Link 1.7.11 or newer in the booth.

LJL Link is an independent program for users of Serato DJ Pro. It is not a product of, not affiliated with and not endorsed by Serato. Serato and Serato DJ Pro are trademarks of Serato.

What LJL Link is

Serato DJ Pro has no public interface that LJ Link could use for decks, waveforms and position. Without help, LJ Link therefore reads Serato only on the same computer, and without a playhead (Serato DJ Pro).

LJL Link – LJ LAN Link – is a separate small app for the DJ’s Mac with Serato DJ Pro. It runs from the club’s USB stick, nothing is installed. It follows along passively and sends the deck data over the local network to LJ Link in the booth: which track is on which deck, its length, BPM and key, three-band waveforms and the running position. In LJ Link the Serato decks appear next to every other player, so LJ Link no longer has to run on the DJ’s computer.

Download: latest release · website: LJL Link · source code: github.com/skyplayser/LJL-Link · privacy policy of LJL Link

What it sends

DataWhere it comes from
Title, artistSerato’s log file names the file on each deck, the tags of the file give title and artist. Only if the DJ allows track names (see below).
LengthSerato’s log file
BPM, keythe tags Serato wrote into the file
Waveformsdetail and overview in three bands, built by LJL Link from the audio file on the DJ’s Mac; the audio itself never leaves the Mac
Positionread from the time display in Serato’s window, about 4 to 5 times a second; in between LJ Link runs the playhead on at the measured speed. Needs the permission Screen Recording
Name of the Mac, LJL Link versionfrom the system settings; LJ Link shows with it whose decks these are
Never sentfile names, folders, the audio itself
Not sent (yet)beat grid, cues, loops, cover, channel faders

Each loaded track gets a random id; the file path is never sent. Details in the privacy policy of LJL Link.

Preparing the stick (preliminary, alpha)

For now there is no button for this in LJ Link; an interface to prepare the stick follows later. Until then, on the computer that runs LJ Link:

  1. Download LJL Link from the latest release and copy LJL Link.app onto the USB stick.

  2. In a browser on this computer open http://127.0.0.1:8080/api/sender/club.json. 8080 is the standard port; if LJ Link uses another one, put that port instead. This address works only on the computer that runs LJ Link, not on a tablet.

  3. Save the file as club.json on the stick, next to LJL Link.app. It holds the club name, the addresses and port of the booth computer and the club key.

The file looks like this (the values come from LJ Link):

{
  "version": 1,
  "club": "<name shown to the DJ>",
  "hosts": ["<address of the booth computer>"],
  "port": <LJ Link's port>,
  "key": "<club key from LJ Link>"
}

!Warning

Without club.json LJL Link may still find LJ Link by Bonjour, but it does not have the club key, so no connection is made.

iInfo

The club key is a random key that LJ Link creates by itself; it is no one’s password. A new key in LJ Link makes every older stick invalid at once: LJL Link then says that the club key on this stick is no longer valid, and the stick has to be prepared again.

Planned: Prepare stick in LJ Link writes LJL Link and club.json onto the stick in one go. A stick prepared that way carries no download flag, so macOS does not warn at the first start.

Setting up at the gig

  1. In the booth the LJ prepares the club’s USB stick with LJL Link and club.json (see above).

  2. The DJ plugs in the stick and starts LJL Link from it. Nothing is installed. LJL Link looks for club.json next to itself; if it is not there, the DJ can choose the file by hand (Choose club.json …).

  3. On the first start macOS asks for Local Network and Screen Recording (see below), and LJL Link asks once whether track names may go to the lighting booth (see below).

  4. LJL Link connects to LJ Link: first to the addresses in club.json, then to every LJ Link it finds in the network by Bonjour, in case the booth computer got a new address since the stick was prepared. LJ Link accepts it only with its current club key.

  5. The DJ loads a track in Serato as usual: the deck appears in LJ Link, the waveform follows as soon as LJL Link has built it.

  6. At the end of the set: Quit in LJL Link (or ⌘Q), then unplug the stick. Closing the window is not enough, LJL Link keeps sending from the menu bar.

In LJ Link

  • The decks from LJL Link replace the start page, and the status says Connected. The name of the DJ’s Mac shows whose decks these are.
  • Up to 4 LJL Links can be connected at once, for example for a DJ change.
  • A deck whose time cannot be read shows NO POSITION (see problems).

Track names only with the DJ’s permission

At the start LJL Link asks: Send track names to the lighting booth? Without track names LJ Link only gets tempo, key, waveform and position; titles, artists and file names do not leave the DJ’s Mac, and LJ Link shows Title hidden by the DJ. The DJ can change this any time, in the window or in the menu bar. Switched off, LJ Link removes the titles at once, on tablets too.

First start on the DJ’s Mac

LJL Link is ad-hoc signed, but not notarized by Apple yet. So macOS blocks a copy downloaded from the internet once on the first start (“LJL Link” Not Opened):

  1. Start LJL Link once and click Done at the warning.

  2. Open System Settings → Privacy & Security, scroll down, click Open Anyway next to LJL Link and confirm with your password or Touch ID, then Open.

On macOS 14 a right-click on the app → Open → Open also works. More, including a Terminal alternative: LJL Link README.

Two questions from macOS

  • Local Network: Allow. So LJL Link finds LJ Link in the booth, and for the suite chat in the same network.
  • Screen Recording: LJL Link uses it only to read the time display in Serato’s window, so the waveform in LJ Link runs along (details in the privacy policy of LJL Link). Nothing is stored or sent except the time. Without it LJL Link still sends tracks and waveforms, only without the running position. macOS applies a new permission only after LJL Link is started again (Restart app).

Passive

LJL Link does not control Serato and never touches controllers or MIDI. It reads Serato’s log file, the loaded files and the time display in Serato’s window. Nothing it sends can control LJ Link, Serato or any device. It has no account, no cloud and no telemetry and opens no connection to the internet.

Booth chat and EMERGENCY

LJL Link is in the suite chat (alpha) with the other suite programs in the network, such as LJ Link in the booth and VJ-Link: one chat room without a server, so the DJ and the booth can write to each other instead of shouting across the dance floor. EMERGENCY opens a pop-up for everyone. The DJ can switch the chat off in LJL Link. Messages are kept only in memory and never written to a file, a log or a problem report. How the chat works: Suite chat.

!Warning

The chat is not encrypted: every device in the same network can read along. Do not write anything confidential. EMERGENCY is no alarm or safety system: it can fail or arrive late, anyone in the network can trigger it, and it does not replace announcements, radios or the event’s safety plan.

Limits of the alpha

  • Not tested in a real club yet, only in our own tests on one Mac.
  • Not notarized by Apple, only signed ad hoc (first start).
  • Only on a Mac, with Serato DJ Pro on the same Mac: needs macOS 14 or newer; tested with Serato DJ Pro 5.0 on one Mac, no promise for other versions.
  • No position for a deck whose time cannot be read, for example decks 3 and 4 in Serato’s 2-deck view, without the permission Screen Recording, or while LJL Link is still calibrating.
  • No beat grid, cues, loops, cover or channel faders from LJL Link yet.
  • Needs LJ Link 1.7.11 or newer: the input for LJL Link is in a release there for the first time, and it is an alpha too.
  • LJL Link offers the club key to every LJ Link in the network that accepts LJL Link. The LJ Link of another club refuses it, and LJL Link tries the next one.
  • The stick is prepared by hand for now; Prepare stick in LJ Link is planned.

Still stuck? Use Report a problem in LJL Link: describe what happens and leave Include diagnostic data ticked. The diagnostic data holds no track titles, artists, file names or the club key, and you see it before sending. Or ask on Discord.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
