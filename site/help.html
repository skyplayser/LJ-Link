HelpHelp and debugging

Known problems and how to solve them. If yours is missing, report it – with diagnostic data we can help fastest.

Known problems

A player shows up, but says “No track loaded” or has no waveform
  1. Update to 1.4.1 or newer: older versions showed tracks without rekordbox analysis as “No track loaded”.
  2. Play tracks from a USB stick or SD card that was exported with rekordbox (Export mode, tracks analysed). Tracks from streaming services, CDs or files that were never analysed have no waveform data.
  3. On a CDJ-3000 with current firmware: export with rekordbox 6 or 7 to the stick again after updating rekordbox.
  4. Do not run rekordbox (with “Link” or “Performance” mode) on the same computer: it occupies the same network ports.
  5. Still nothing? Send a report with diagnostic data (see below); it shows what the player reports for the track.
Known bug: with a direct cable (no router) and Wi-Fi on, players show up twice or not at all
  1. This happens now and then and is not fixed yet. Without a router the computer and the players give themselves addresses (169.254.x.x); with Wi-Fi on, the computer can then send on the wrong adapter or receive every packet twice.
  2. Quick help: quit LJ Link (program icon → Quit) and start it again, then “Search automatically”. That usually solves it.
  3. If it comes back: switch Wi-Fi off while you work with a direct cable, or use a small switch or router between computer and players.
  4. If you see it, please send a report with diagnostic data (Report a problem → Send by email) while the problem is on screen; it helps us fix it.
A player shows up twice
  1. Use only one network connection: turn Wi-Fi off when the computer is connected by cable. If Wi-Fi and cable are in the same network, every DJ Link packet arrives twice.
  2. Switch off virtual network adapters you do not need (VPN, Parallels, VMware, VirtualBox, Hyper-V, Docker).
  3. Give every player its own number (on the player: Utility → Player No.). Two players with the same number, or LJ Link started twice, look like one player twice.
  4. If the computer has no address from a router (169.254.x.x) while the players have one, connect it to the same switch or router as the players.
Nothing is found
  1. Computer, players and mixer must be on the same network switch, connected with cables. A direct cable from the computer to one player also works.
  2. Windows: allow LJ Link in the firewall for private networks (Windows Security → Firewall & network protection → Allow an app through firewall). If the network is set to “Public”, switch it to “Private”.
  3. macOS: allow “Local Network” for LJ Link (System Settings → Privacy & Security → Local Network).
  4. Use “Set up manually” in the program: it checks the address of a player step by step and says what to change.
Yellow note “Beat port 50001 is in use”
  1. Another program listens for beats: rekordbox, Beat Link Trigger, SoundSwitch or a second LJ Link. Close it and start the search again. Until then positions are estimated.
The waveform of a CDJ-2000NXS2 jumps
  1. NXS2 and older players only report their position between beats. LJ Link runs them at their pitch; small jumps after a cue or loop are normal. The CDJ-3000 reports its exact position.
A Denon device is not found or keeps reconnecting
  1. Update to 1.3.1 or newer (1.3.0 could reconnect in a loop).
  2. Close Engine DJ and other StageLinQ programs (SoundSwitch, Resolume …) on the same computer; they use the same port.
  3. After a connection broke, the device needs a few seconds before it accepts a new one.
The light desk does not react
  1. grandMA2: switch Telnet on (Setup → Console → Global Settings → Telnet: Login Enabled). The user needs enough rights: “Error #44 INSUFFICIENT USER RIGHTS” means the user may not change masters.
  2. grandMA2 takes whole BPM only; LJ Link 1.3.0 and newer send them that way.
  3. grandMA3: In & Out → OSC: Receive Command = Yes and Enable Input. Leave the prefix empty.
  4. Check that the effect runs on the speed master you send to (Speed 16 = BPM by default).
  5. Details: the light desk guide.
No icon in the menu bar (Mac) or next to the clock (Windows)
  1. If LJ Link is already running, a second start only opens the interface and quits; close the first one.
  2. macOS: check System Settings → Menu Bar whether LJ Link is allowed there.
  3. Windows: the icon may be hidden behind the arrow next to the clock; drag it out.
“Check for updates” fails
  1. Versions 1.2.x cannot check for updates in the installed program (“Handshake failed”). Install the newest version once by hand; from 1.3.0 on it works.
  2. The check needs the internet; in a show network without internet it says it could not reach GitHub.
Serato decks have no playhead
  1. That is a limit of Serato: it does not reveal the play position. LJ Link shows the loaded track with BPM, key, waveform overview and beat grid from the file. FLAC and M4A files are not read yet.

Report a problem

  1. Keep LJ Link open while the problem happens (leave the gear connected).
  2. In the program: menu (☰) → “Report a problem”, or “Report a problem …” in the menu of the program icon.
  3. Describe what happens: which gear, which firmware, Windows or Mac, what you see.
  4. Leave “Include diagnostic data” ticked. It holds the version, network adapters, the devices found and their connection state, what each deck receives and the last log lines – no track titles, no covers, no passwords. “Show diagnostic data” shows everything before you send it.
  5. “Send by email” opens your mail program with a ready mail to fehlermelden@nextphilm.de (long diagnostics are saved as a file to attach). Or “Report on GitHub” (GitHub account needed).
