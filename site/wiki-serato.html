DJ sourcesLJ Link: Serato DJ Pro

LJ Link is an independent program for use with Serato DJ Pro. It is not a product of, not affiliated with and not endorsed by Serato.

Loaded tracks with waveform and beat grid, on the DJ’s computer.

βBeta

Works with Serato DJ Pro 3.x on macOS with MP3 and AIFF. Windows is expected to work but not tested yet.

How it works

Serato DJ Pro has no public interface that LJ Link could use for decks, waveforms and position. While it runs, it writes a log file that names the file on each deck. LJ Link follows this log file and reads title, artist, BPM, key, length, waveform overview, beat grid and cues from the tags Serato writes into the file.

!Warning

That is why LJ Link must run on the same computer as Serato. Over the network it works only with LJL Link, a separate app for the DJ’s Mac (alpha).

Step by step

  1. Install LJ Link on the DJ’s laptop and start Serato DJ Pro.

  2. Search automatically. As soon as a track is loaded, its deck appears.

  3. The lighting jockey watches on a tablet or a second computer: open the address shown under the toolbar in the same network. See Serato on the DJ laptop.

Limits

  • No play position: Serato DJ Pro has no public interface for it that LJ Link could use, so there is no moving playhead. With LJL Link (alpha) the position comes from the time display in Serato’s window.
  • Tempo is the track BPM from the file, not the pitched tempo. For the live tempo switch on Ableton Link in Serato (Ableton Link).
  • FLAC and M4A are not read yet. Files without Serato tags show only the file name.
  • No on-air or master information.

LJL Link: deck data from the DJ’s Mac (alpha)

αAlpha: untested

LJL Link is new and an alpha. It has not been tested in a real club yet and is not notarized by Apple. Do not rely on it for a show; keep a fallback ready. It needs LJ Link 1.7.11 or newer in the booth.

LJL Link is a small app for the DJ’s Mac with Serato DJ Pro. It sends the deck data over the network to LJ Link in the booth: track, length, BPM, key, waveforms and the position. So LJ Link no longer has to run on the DJ’s computer. Without LJL Link, LJ Link reads Serato only on the same computer, as described above.

Project page and source code: github.com/skyplayser/LJL-Link. LJL Link, like LJ Link, is an independent program. It is not a product of, not affiliated with and not endorsed by Serato.

What it sends

DataWhere it comes from
Title, artistSerato’s log file names the file on each deck, the tags of the file give title and artist. Only if the DJ allows track names.
LengthSerato’s log file
BPM, keythe tags Serato wrote into the file
Waveformsdetail and overview in three bands, built by LJL Link from the audio file on the DJ’s Mac
Positionread from the time display in Serato’s window, about 4 to 5 times a second; in between LJ Link runs the playhead on at the measured speed. Needs the permission Screen Recording
Not sentbeat grid, cues, loops, cover, channel faders

Preparing the stick (preliminary, alpha)

For now there is no button for this in LJ Link; an interface to prepare the stick follows later. Until then, on the computer that runs LJ Link:

  1. Copy LJL Link.app onto the USB stick.

  2. In a browser on this computer open http://127.0.0.1:8080/api/sender/club.json. 8080 is the standard port; if LJ Link uses another one, put that port instead. This address works only on the computer that runs LJ Link, not on a tablet.

  3. Save the file as club.json on the stick, next to LJL Link.app. It holds the club name, the addresses and port of the booth computer and the club key.

!Warning

Without club.json LJL Link may still find LJ Link by Bonjour, but it does not have the club key, so no connection is made.

Setting up

  1. In the booth the LJ prepares the club’s USB stick with LJL Link and club.json (see above).

  2. The DJ plugs in the stick and starts LJL Link from it. Nothing is installed. LJL Link looks for club.json next to itself; if it is not there, the DJ can choose the file by hand (Choose club.json …).

  3. LJL Link asks once whether track names may go to the lighting booth (see below).

  4. LJL Link connects to LJ Link: first to the addresses in club.json, then to every LJ Link it finds in the network by Bonjour, in case the booth computer got a new address since the stick was prepared. LJ Link accepts it only with its current club key. Up to 4 LJL Links can be connected at once.

  5. The DJ loads a track in Serato: the deck appears in LJ Link, the waveform follows as soon as LJL Link has built it.

  6. At the end of the set: Quit in LJL Link (or ⌘Q), then unplug the stick. Closing the window is not enough, LJL Link keeps sending from the menu bar.

iInfo

The club key is a random key that LJ Link creates by itself; it is no one’s password. A new key in LJ Link makes every older stick invalid at once: LJL Link then says that the club key on this stick is no longer valid, and the stick has to be prepared again.

Track names only with the DJ’s permission

At the start LJL Link asks: Send track names to the lighting booth? Without track names LJ Link only gets tempo, key, waveform and position; titles, artists and file names do not leave the DJ’s Mac, and LJ Link shows Title hidden by the DJ. The DJ can change this any time, in the window or in the menu bar. Switched off, LJ Link removes the titles at once, on tablets too.

Two questions from macOS

  • Local Network: so LJL Link finds LJ Link in the booth, and for the suite chat in the same network.
  • Screen Recording: LJL Link uses it only to read the time display in Serato’s window, so the waveform in LJ Link runs along (details in the privacy policy of LJL Link). Nothing is stored or sent except the time. Without it LJL Link still sends tracks and waveforms, only without the running position. macOS applies a new permission only after LJL Link is started again (Restart app).

Passive

LJL Link does not control Serato and never touches controllers or MIDI. It reads Serato’s log file, the loaded files and the time display in Serato’s window. Nothing it sends can control LJ Link, Serato or any device.

LJL Link is also in the suite chat (alpha) with the other suite programs in the network, such as LJ Link in the booth; the DJ can switch the chat off.

Limits of the alpha

  • Not tested in a real club yet, only in our own tests.
  • Not notarized by Apple, only signed ad hoc. macOS may warn at the first start, above all for a copy downloaded from the internet. How to open it anyway: LJL Link README.
  • Only on a Mac, with Serato DJ Pro on the same Mac: needs macOS 14 or newer; tested with Serato DJ Pro 5.0 on one Mac, no promise for other versions.
  • No position for a deck whose time cannot be read, for example decks 3 and 4 in Serato’s 2-deck view, without the permission Screen Recording, or while LJL Link is still calibrating. LJ Link then shows NO POSITION.
  • Needs LJ Link 1.7.11 or newer: the input for LJL Link is in a release there for the first time, and it is an alpha too.
  • LJL Link offers the club key to every LJ Link in the network that accepts LJL Link. The LJ Link of another club refuses it, and LJL Link tries the next one.

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
