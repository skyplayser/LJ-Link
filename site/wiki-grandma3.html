Light deskgrandMA3 and onPC

The tempo of the DJs on a speed master of your show, over OSC.

Status

Beta

Beta: the OSC settings and the command Master 3.1 At BPM {bpm} come from the grandMA3 manual and were tested against a simulation. They have not been confirmed on a real grandMA3 or onPC yet. If you try it, please tell us how it went.

How it works

The grandMA3 takes commands for its command line over OSC (address /cmd, text). LJ Link sends the command for the speed master there.

1. On the desk: set up the OSC input

  1. Open Menu → In & Out → tab OSC.
  2. At Interface choose the network card through which the computer with LJ Link can be reached.
  3. In the table create a row (or use an existing one) with the values below.
  4. Switch Enable Input on. When OSC arrives, the title bar of Enable Input lights up yellow.
FieldValue
ModeUDP
Port8000, or another free port; it must be the same in LJ Link
Prefixleave empty
Receive CommandYes (otherwise commands are ignored)
Receivedoes not matter (only for data to faders and keys)
EchoInputYes for testing: incoming messages show in the System Monitor

About the prefix: if it says gma3, the desk expects /gma3/cmd instead of /cmd. LJ Link sends to /cmd, so leave the field empty.

2. On the desk: check the speed master

  1. Assign the effect or sequence to a speed master (the first is Master 3.1).
  2. Test in the command line: type this and press Enter. The speed master should be at 120 BPM.
Master 3.1 At BPM 120

3. In LJ Link

  1. Open the menu (☰) → Light desk link (send tempo), or the tab LINK.
  2. Choose grandMA3 / grandMA3 onPC (OSC).
  3. Enter the IP address of the desk (onPC on the same computer: 127.0.0.1). The search does not find a grandMA3 yet, so enter it by hand.
  4. Port as on the desk, for example 8000.
  5. The command is Master 3.1 At BPM {bpm} by default.
  6. Press Save, then Send test (120 BPM). With EchoInput on you see the message in the System Monitor.

Problems

The desk does not react
  1. In & Out → OSC: is Receive Command Yes and Enable Input on? Is the prefix empty? Do the ports match?
  2. Is the computer in the same network, and the right network card chosen as Interface?
  3. Does the manual test Master 3.1 At BPM 120 work? And is the effect assigned to that speed master?

Tried it? Tell us

Every report helps to turn a beta or alpha into a tested feature, also when it does not work. In LJ Link open the menu (☰) → “Report a problem” and send it by email or on GitHub. Please add your device, its firmware, the software version and what you saw.
