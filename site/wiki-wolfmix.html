Light deskWolfmix

Tempo and every beat of the DJs to the Wolfmix, through the app WTOOLS.

Status

Alpha

Untested alpha feature. The Wolfmix connection has never been tried on a real Wolfmix. It was only checked against a test receiver on the development computer. It may not work at all or only in part. Do not use it for the first time at an important event, and keep a plan B ready (the tap button of the Wolfmix or its audio detection). If you try it, please tell us the result, also when it does not work.

How it works

The Wolfmix has no network connection, only USB and DMX. It can only get the tempo through a computer it is plugged into by USB, using the maker’s app WTOOLS. LJ Link talks to WTOOLS over OS2L (Open Sound to Light, the protocol VirtualDJ uses) and sends not only the tempo but every single beat. Effects and chasers of the Wolfmix then run in time with the DJs.

CDJs / Denon / Serato  →  LJ Link  →(OS2L)→  WTOOLS  →(USB)→  Wolfmix  →(DMX)→  lights

What you need

  • A Wolfmix (W1 MK1, MK2 or MK3), plugged into a computer by USB.
  • The app WTOOLS from Wolfmix on that computer.
  • LJ Link 1.5.0 or newer, best on the same computer. Then the address is 127.0.0.1. On another computer in the network it may work too, but that is not tested.
  • The players LJ Link takes the tempo from (Pioneer, Denon, Serato).

Set up, step by step

  1. Plug the Wolfmix into the computer by USB and start WTOOLS. The Wolfmix must be recognised there.
  2. In WTOOLS switch OS2L on. (The maker’s guide says: connect the Wolfmix, open WTOOLS, click the OS2L button. The name can differ a little between versions.)
  3. In LJ Link open the menu (☰) → Light desk link (send tempo) → Wolfmix (OS2L, WTOOLS) – Alpha.
  4. Address 127.0.0.1 (WTOOLS on the same computer), port 5000. Press Save.
  5. Press Send test (120 BPM). LJ Link sends eight beats at 120 BPM, one every half second. The line below the button counts the messages. If it says “No OS2L receiver at …”, see Problems below.
  6. On the Wolfmix, in the FX rack, push the first encoder so the effect follows the BPM (BPM sync). Without that nothing seems to happen.
  7. Load a deck and play it. SEND BPM says which deck gives the beat (Auto takes the master). The effects should now run on the beat.

What LJ Link sends

  • On every beat one message with the beat number, the tempo and a hint “change”.
  • The beat number is counted so that every fourth beat is the one of a bar, following the beat grid of the player.
  • “Change” is set after a start, after a jump (cue, loop, seeking), with another track or deck and when the tempo changes by more than 0.5 BPM.
  • While the deck stands, or runs backwards, no beats are sent.
  • Serato and Ableton Link give no play position. There the beat runs freely at the tempo of the loaded track, even when the track is not playing, and there is no real phase.
  • The demo never sends.
  • Not sent: buttons, track titles, waveforms, drops or phrases. That could come later.

Problems

“No OS2L receiver at 127.0.0.1:5000”
  1. WTOOLS is not running, OS2L is off, or WTOOLS listens on another port. Start WTOOLS, switch OS2L on, look at the port in WTOOLS and enter it in LJ Link.
  2. LJ Link tries again every 5 seconds, so the order of starting should not matter.
Messages are counted, but the Wolfmix does not react
  1. Push the first encoder in the FX rack (BPM sync).
  2. Restart WTOOLS and then LJ Link.
  3. Close other programs that use port 5000 or send OS2L as well, for example VirtualDJ.
It runs, but slightly beside the beat
  1. Network, WTOOLS and USB take some time. A setting to compensate this is planned but not built yet. Please report by how many milliseconds it is off.

What is not tested or not known

  • Everything on a real Wolfmix. Against the test receiver the beats were on average 1.5 ms off the beat (at most 7 ms). WTOOLS and USB come on top of that, and we have not measured them.
  • The OS2L description names no character between messages. LJ Link ends each message with a line feed. If WTOOLS stumbles over that, it is the first suspect.
  • Whether WTOOLS accepts connections from another computer, or only from the same one.
  • Whether the Wolfmix can map OS2L buttons to presets. LJ Link sends no buttons.
  • The online manuals of the maker are partly older than the current firmware. Our assumptions come from them.
