WikiDJ gear and software

What LJ Link can read from which gear or program, and what each one can show. LJ Link only listens; it never controls the gear.

Overview

SourceStatusWhat is shownLimits
Pioneer DJ (CDJ, XDJ, DJM) over Pro DJ LinkStableTrack, waveforms, beat grid, cues, loops, position, tempo, master, on airThe CDJ-3000 reports its exact position; NXS2 and older estimate it between beats. Tracks without rekordbox analysis have no waveform.
Denon / Engine DJ over StageLinQ (several devices at once)StableTrack, waveform overview, beat grid, cues, loops, position, tempo, master, fadersThe library only gives an overview of 1024 values per track; the detail view is interpolated from it. Key, pitch and EQ are not transmitted.
Serato DJ Pro on the same computerBetaTrack, BPM, key, waveform overview, beat grid, cuesSerato does not reveal the play position, so there is no playhead. FLAC and M4A files are not read yet.
Ableton Link (Serato, Traktor, rekordbox, Ableton Live and many apps)BetaThe shared tempo of a Link sessionTempo only, no tracks or waveforms. LJ Link only listens and never joins the session.

Pioneer DJ

  • Computer, players and mixer must be on the same network switch, connected with cables. A direct cable from the computer to one player also works.
  • Do not run rekordbox on the same computer at the same time: it occupies the same network ports.
  • Known bug: with a direct cable and Wi-Fi on, players can show up twice or not at all. A restart of LJ Link helps; details on the help page.

Known bug: direct cable and Wi-Fi

Denon DJ / Engine DJ

  • LJ Link finds Denon devices (Prime and others) through StageLinQ automatically. Several devices can run next to each other and next to Pioneer players.
  • Close Engine DJ and other StageLinQ programs on the same computer: they use the same port.

More about Denon and StageLinQ

Serato DJ Pro

Serato has no public live interface. LJ Link follows the log that Serato writes while it runs, which names the file of every track loaded to a deck, and reads title, artist, BPM, key, length, waveform overview, beat grid and cues from the tags Serato wrote into the file. Serato must run on the same computer as LJ Link.

  • No play position, so no playhead on the waveform.
  • Files without Serato tags show only the file name.

Tried it? Tell us

Every report helps to turn a beta or alpha into a tested feature, also when it does not work. In LJ Link open the menu (☰) → “Report a problem” and send it by email or on GitHub. Please add your device, its firmware, the software version and what you saw.
