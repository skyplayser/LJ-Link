What is sent, and when

  • LJ Link only sends the tempo (or, for Wolfmix, the beats). It starts no cues, changes no show and sends nothing to the DJ gear.
  • Over OSC the tempo is sent when it changes by 0.1 BPM or more, and repeated every 2 seconds. To a grandMA2 it is repeated every 15 seconds so the command line does not fill up.
  • A speed master only moves effects and chasers that are assigned to it. If nothing moves although the tempo arrives, the effect is almost always not assigned to the speed master.
  • The demo mode never sends anything to a desk.

Which deck gives the tempo (SEND BPM)

At the top of LJ Link the tab SEND BPM says where the tempo comes from:

  • Auto: the deck that is master and/or live (on air at the mixer). With two systems, say CDJs and a Denon, the master that is also live and playing wins.
  • One chosen deck: always this deck, even if another one is live. Without a track on it nothing is sent.
  • The deck that sends shows a green SEND BPM next to its fader bar.

Before you start: the network

  1. Computer and desk must reach each other. The simplest is the same network switch as the DJ players. If the desk is in its own lighting network, the computer needs a second network card (for example a USB adapter) in that network.
  2. Find the IP address of the desk. grandMA2: Setup → Network → Network Interface. grandMA3: Menu → Network → Interfaces. onPC on the same computer as LJ Link: simply 127.0.0.1.
  3. Same network? With the usual mask 255.255.255.0 the first three groups of numbers must match: 192.168.1.10 and 192.168.1.50 fit, 10.0.0.5 does not.
  4. onPC on another computer: allow “Private networks” in the Windows firewall when onPC asks. If you declined: Windows Security → Firewall → Allow an app through the firewall → grandMA onPC.

Tried it? Tell us

Every report helps to turn a beta or alpha into a tested feature, also when it does not work. In LJ Link open the menu (☰) → “Report a problem” and send it by email or on GitHub. Please add your device, its firmware, the software version and what you saw.
