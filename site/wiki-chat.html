StartSuite chat

Booth, FOH and VJ write to each other across the floor, with an EMERGENCY button for when it matters. Alpha.

αAlpha: untested

New in 1.7.11. Tried only on one Mac, with several suite programs on the same computer. Not tested between two computers and not on Windows. Do not rely on it at an important event; keep a radio or a phone ready.

What it is

Lighting booth, DJ booth and VJ often have to shout across the floor: “drop in 30 seconds”, “more fog?”. The suite chat is one chat room for LJ Link and the other programs of the suite that have the chat, for example VJ-Link and LJL Link on the DJ’s Mac. Every suite program in the same network joins by itself. There is no server and no account: whoever is in the network with a suite program is in the room, also when LJ Link is not running.

Open the chat

  • Chat button at the bottom right of the interface. It is shown only in the browser on the computer running LJ Link, not on a tablet or phone.
  • Or the program icon (menu bar or next to the clock) → Open suite chat (alpha). This opens the interface with the chat open.

The first time, the chat asks two things: Name – What is your name? (for example DJ David) and Position – Where are you? (for example FOH, DJ Booth, Bar). Then Join chat. Both are shown with every message, as “name (position) · LJ Link”. Change name at the top of the chat changes them later. The top line shows who is in the room.

When you join or switch the chat on again, the others send their last messages again (up to 20 each), so you see what was written just before. This can take up to about 12 seconds. Every message shows a time: for new messages the time they arrived here, for these earlier ones the time they were sent.

Write and EMERGENCY

Type into Message to everyone and press Send (or Enter). Every message goes to everyone in the room; there are no private messages.

EMERGENCY next to Send is for when it really matters. With an empty text field it sends “EMERGENCY – please come at once!”. Everyone else gets a pop-up at once:

  • at the bottom right of the screen, with a yellow blinking border, with name, position, program and text;
  • in LJ Link also as a window of its own, always in front, also when no browser is open (LJ Link often runs only as the program icon). It does not take the keyboard from the program you are working in;
  • it stays until OK. OK in the window or in the browser closes it in both. With two or more open, Close all appears; it closes only the ones already shown, one that arrives just then stays open.

✎Note

The chat never plays a sound: the output of the computer may be connected to the mixer. The word EMERGENCY stays the same in every language.

!Warning

EMERGENCY is no alarm or safety system and no substitute for emergency calls, fire alarms, radios or security staff. Messages can be lost or arrive late, and anyone in the network can write under another name.

New messages

What you seeMeaning
Number at the Chat buttonnew messages from the others while the chat is closed; your own messages and the earlier messages sent when you join do not count
Number at the program icon, Open suite chat (alpha) – 2 new in its menuthe same, also when no browser is open
Chat button blinks yellow (the circle at the program icon too)an EMERGENCY came that you have not seen in the chat yet. It blinks until you open the chat; OK on the pop-up does not stop it. With “reduce motion” on in the system the button stays yellow instead of blinking (on a Mac also the window border and the circle at the program icon)

Switch it off

Menu (☰) → Suite chat – Alpha → Chat with all suite programs in this network. On by default; shown only on the computer running LJ Link. Switched off, LJ Link neither sends nor reads chat messages, the Chat button goes, the menu item at the program icon is greyed out, open pop-ups close, and LJ Link forgets every chat message in memory (the browser empties its list too). Switched on again, the others send their last messages.

Limits

WhatLimit
Message500 characters, text only; line breaks become spaces
Name, position24 characters each
Messages per participant10 in 10 seconds, more are dropped
EMERGENCY per participant3 in a minute with a pop-up; more arrive as normal messages
Open EMERGENCY pop-ups20 at most; more arrive as normal messages
Keptthe last 200 messages, only in memory; they are gone when the chat is switched off or LJ Link quits

Privacy

  • Every device in the same network can read along, and anyone there with a suite program can write. Nothing is encrypted. Do not write anything you would not say out loud in the booth.
  • Nothing leaves the local network: the chat uses multicast with a time to live of 1, so routers do not pass it on. No internet, no cloud.
  • Chat texts are never written to a log, a file or a problem report. A report only says whether the chat is on and how many messages are in memory, other programs are in the room and emergencies are open, never texts or names. LJ Link keeps your name, position and the on/off setting in its settings.
